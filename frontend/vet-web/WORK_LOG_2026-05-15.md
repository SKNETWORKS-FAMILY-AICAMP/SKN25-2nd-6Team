## 5. 로그인 응답 처리

### access token 처리 가능 형태

- `access_token`
- `accessToken`
- `token`
- `data.access_token`
- `data.accessToken`
- `data.token`

### 처리 이유

- 백엔드 응답 구조가 명확히 고정되지 않았을 가능성 대비
- 응답 구조가 조금 달라도 프론트가 바로 깨지지 않게 처리

### access token이 없을 경우 표시되는 에러

```text
로그인 응답에서 인증 토큰을 찾을 수 없습니다.
```

## 9. 비밀번호 정책 검사

### 프론트에서 검사하는 정책

- 8자 이상 20자 이하
- 영문 포함
- 숫자 포함
- 특수문자 포함
- 아이디와 동일한 비밀번호 사용 불가
- 동일 문자 3회 이상 반복 불가
- 연속 문자 사용 불가

### 관련 함수

```ts
isPasswordPolicyValid()
getPasswordPolicyStatus()
```

### 화면 표시

- 정책별 체크 아이콘 표시
- 입력값에 따라 충족 여부 실시간 반영

## 10. 비밀번호 변경 API 연동

### 수정 파일

```text
frontend/vet-web/src/api/authApi.ts
frontend/vet-web/src/pages/auth/FirstPasswordChangePage.tsx
```

### 실제 API 호출

```text
PUT http://192.168.0.2:8001/doctor/auth/password/change
```

### Header

```text
Authorization: Bearer {access_token}
```

### Request body

```json
{
  "current_password": "현재 비밀번호",
  "new_password": "새 비밀번호",
  "new_password_confirm": "새 비밀번호 확인"
}
```

---

## 11. 비밀번호 변경 응답 처리

### 백엔드 명세 반영

```ts
interface PasswordChangeResponse {
  code: number;
  message: string;
}
```

### 성공 응답

```json
{
  "code": 200,
  "message": "비밀번호가 변경되었습니다."
}
```

### 성공 처리

- 기존 access token 유지
- `isFirstLogin` 값을 `false`로 변경
- 대시보드 화면으로 이동

### 실패 처리

- 백엔드에서 내려준 `message`를 화면에 표시

### 예상 에러 메시지

- 새 비밀번호가 일치하지 않습니다.
- 현재 비밀번호가 올바르지 않습니다.
- 비밀번호는 8자 이상 20자 이하, 영문, 숫자, 특수문자를 포함해야 합니다.
